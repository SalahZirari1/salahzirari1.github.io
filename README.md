# Salah Zirari

Personal portfolio: full-stack tech lead, .NET & Azure, Lyon.
Live at https://salahzirari1.github.io

Built with React, TypeScript and Vite. French and English.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text lives in `src/content.ts`, with a French and an English version of each string.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`).
